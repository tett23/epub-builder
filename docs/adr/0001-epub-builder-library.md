# ADR 0001: EPUB 2.0.1 と 3.0 を作るライブラリを、Deno で動く TypeScript の公開リポジトリとして MIT ライセンスで作る

ステータス: 採択

## 文脈

Web 小説を EPUB にする [epubize](https://github.com/tett23/epubize) では、EPUB のファイルを作る部分が要る。
EPUB を作る処理は、小説や取得元のサイトに関わらない。独立したライブラリにすれば、epubize 以外からも使え、仕様への適合も単独で確かめられる。
読む側の端末には、EPUB 3 に対応しないものもあるため、EPUB 2.0.1 も出せるようにしたい。

## 実装すること

- EPUB のファイルを作るライブラリを、このリポジトリ `epub-builder` で作る
- 対応する仕様は EPUB 2.0.1 と EPUB 3.0 とする。詳細は ADR 0003 で決める
- 実装の言語は TypeScript とし、Deno で動かす。設定とタスクは `deno.json` に置き、整形、lint、型検査、テストは Deno の機能で行う
- リポジトリは公開とし、ライセンスは MIT とする
- GitHub Actions で、整形、lint、型検査、テストを push と pull request のたびに行う

## 実装しないこと

- 小説や特定のサイトに固有の処理（本文の取得、整形など）は持たない
- EPUB を読む、または書き換える処理は持たない
- Node.js やブラウザで動くことは、この時点では保証しない

## テスト設計

- 方針の決定であり、この時点ではライブラリのコードを伴わないため、ライブラリのテストはない
- テストのフィクスチャは、著作物を含まない合成データで作る

## トレードオフ

- epubize とは別のリポジトリになるため、両方にまたがる変更は 2 回に分けて行う
- Deno の機能に寄せるため、Node.js で使うには別に対応が要る
